# Broker test plan

What to ask a customs broker to check, and where the answer lives in the code. Every row points
at a golden fixture in `packages/engine/fixtures/quotes/`; each fixture's `notes` field holds the
hand calculation. Run them with `pnpm --filter @harbour/engine test`.

| #   | Test                                                                                                            | What the engine does                                                                                                                        | Fixture(s) | Status                   |
| --- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ------------------------ |
| 1   | **DDP trap.** £5,000 DDP invoice with freight and insurance not itemised.                                       | Duty and VAT computed on the whole £5,000, shown as supplier-borne, excluded from the buyer's totals.                                       | 35, 09     | Built                    |
| 2   | **EXW build-up.** Origin haulage, export clearance, freight and insurance added before duty.                    | Customs value = goods + origin fees + freight to the UK border + insurance.                                                                 | 01         | Built                    |
| 3   | **Import VAT incidental costs.** UK terminal handling and delivery to the first UK destination in the VAT base. | VAT base = customs value + duty + UK haulage + destination handling + clearance.                                                            | 01, 04     | Built                    |
| 4   | **VAT padding when UK costs are unknown.**                                                                      | Optional per-mode figure added to the VAT base only, with a warning. No figure is built in.                                                 | 33, 34     | Built, figures unset     |
| 5   | **Specific and compound duties.** £ per 100 kg, per tonne, per item, compound.                                  | Parsed and multiplied by the entered weight or quantity. MAX/MIN clauses block the quote.                                                   | 14, 15, 18 | Built                    |
| 6   | **Anti-dumping duty.** Bicycles or e-bikes, ceramic tiles from China.                                           | ADD added on top of third-country duty with `ADD_APPLIES`; highest exporter rate if several.                                                | 13         | Built                    |
| 7   | **Exchange rate.** Compare with the HMRC monthly rate.                                                          | The engine uses the HMRC monthly rate itself, the rate customs uses, so there is no spot-rate spread to buffer. ECB is a labelled fallback. | 22         | Built                    |
| 8   | **Assists and tooling.** £1,000 mould over 1,000 units = £1 per unit dutiable.                                  | Assist added to the customs value and to landed cost.                                                                                       | 29         | Built                    |
| 9   | **Postponed VAT accounting.**                                                                                   | Changes cash at the border, not cost. Refused without VAT registration.                                                                     | 31, 32     | Built                    |
| 10  | **Broker deferment fee.**                                                                                       | max(minimum, % × duty and VAT advanced). No default terms.                                                                                  | 30, 31     | Built, terms unset       |
| 11  | **Door incoterms.** DAP and DPU customs value.                                                                  | Invoice minus the supplier's UK leg; blocks without a breakdown.                                                                            | 06, 07, 08 | Built, ADR-0005 proposed |
| 12  | **Preference.** 0% with proof of origin.                                                                        | Only when the origin matches and the user claims it.                                                                                        | 10, 11, 12 | Built                    |
